# Modo Máquina — portal

Site em Next.js (App Router) publicado na Vercel.

## Rodar local
npm install
npm run dev   # http://localhost:3000

## Onde fica o conteúdo
- `lib/content.js` — editorias e artigos (blocos: p, h2, quote, list, callout, img)
- `public/media/artigos/` — imagens dos artigos
- `public/media/instagram/` — artes dos posts (links públicos usados no Metricool)

## Regras editoriais
- Fato/carro real → imagem real com crédito. Ilustração de IA → `ai: true` (mostra o selo).
- Publicidade e afiliados sempre identificados.
